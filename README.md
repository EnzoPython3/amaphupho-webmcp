# Amaphupho WebMCP

Amaphupho is a culturally grounded African dream interpretation platform. This public repository is the clean source mirror used for the OpenAI WebMCP Challenge.

Live application: https://www.amaphupho.co.za

## Provenance

Amaphupho existed before the challenge. This baseline commit represents the relevant pre WebMCP application boundary from private source commit `0deee9d2f2395145fa8bc5b41d53101155339d8f`.

The private production repository also contains unrelated operational history and historical database material, so it is not published. This mirror contains the application interfaces and domain data needed to inspect and verify the challenge extension without exposing that unrelated history.

The next commit adds the WebMCP implementation as a distinct change.
